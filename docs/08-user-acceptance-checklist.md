# 用户侧验收走查清单

> 当前态清单：captain 依仓库证据维护条目，用户照单走查并回填「确认」栏；确认后 captain 据实翻转清单/台账状态（仓库惯例：本地提交与用户侧验收分别记录）。历史确认见 git log 与台账。

## 使用说明

1. 启动：`pnpm dev`（数据库初始化顺序见 README；测试用隔离库，不走生产数据）。
2. 按各条目的「入口」操作，对照「预期」核对。
3. 每条通过后在「确认」栏填 `日期 ✓`；有问题填 `日期 ✗ + 现象一句话`，captain 修复后复验。
4. 条目依据均锚定工程文档证据段，行为细节以证据段为准。
